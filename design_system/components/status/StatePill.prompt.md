StatePill names a state in one word. The colour is the second signal, never the first.

```jsx
<StatePill tone="steady">Steady</StatePill>
<StatePill tone="caution">Stretched</StatePill>
<StatePill tone="risk">Needs attention</StatePill>
```

Never write a bare number or a colour-only dot in place of the word — caregivers do not know the clinical scales.
