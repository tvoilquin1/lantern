TrendRow breaks a stage into the domains a caregiver actually observes.

```jsx
<TrendRow items={[
  { label: "Sleep", value: "Worsening", tone: "caution" },
  { label: "Eating", value: "Steady" },
  { label: "Mobility", value: "Steady" }
]} />
```

Three to four domains maximum. Values are words, never scores.
